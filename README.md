# Traveling Salesman Problem (TSP)
This project focuses on solving the Traveling Salesman Problem (TSP), 
which consists of finding the shortest possible route that visits each city exactly once 
and returns to the starting city.

Different optimization algorithms are implemented and compared 
in order to analyze solution quality and execution time.
## Algorithms
- Nearest Neighbor heuristic
- 2-opt Improvement local search optimization
- Multi-Start with 2-Opt Improvement
- Genetic Algorithm (GA)
